I enjoy bridging the gap between theoretical concepts and practical engineering, from developing backend applications and full-stack platforms to implementing computationally efficient algorithms for real-world robotic systems.

- ⚛️ **Frontend Engineering:** React, JavaScript, TypeScript, and Tailwind CSS.

- Real-time robotic perception and localization.
- Human re-identification and target tracking.
- RGB camera and LiDAR sensor fusion.
- Point-cloud processing and 3D perception.
- State estimation and feedback control.
- Lightweight algorithms for computationally constrained systems.

My master's thesis involved a robotic perception, state-estimation, and feedback-control pipeline under computational constraints, including a statistical similarity approach based on **Bhattacharyya distance** for target tracking under spatial uncertainty.
