### ◈ Engineering & Research Profile

With **21 years of programming experience** and an **MSc in Mechatronics Engineering** (*Top Academic Honors, Rank 1*), I engineer intelligent systems where high-level machine perception meets constrained, real-time edge hardware:

* 🔬 **Intelligent Vision & Inference:** SOTA neural network pipelines, statistical pattern recognition, and human re-identification (Re-ID).
* 🛰️ **Robotic Perception & State Estimation:** Sensor fusion (LiDAR + RGB Vision), visual SLAM, point-cloud reasoning, and deterministic feedback control.
* ⚡ **Performance Under Pressure:** Optimizing heavy ML models for real-time edge compute with tight memory and power budgets.
* 🌐 **Full-Stack Ecosystems:** Complete end-to-end integration—from microcontrollers, C++, and PyTorch kernels up to high-throughput Django backends and React frontends.
